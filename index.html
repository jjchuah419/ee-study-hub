BUILD WITH RULES

關於這個專案

讓知識持續累積，也讓 AI 能按照同一份規範繼續開發。

為什麼建立 EE Study Hub？

電機相關課程常包含公式、觀念與多步驟計算。這個網站把不同科目的重點整理成一致的單元格式，讓複習更有效率，也方便未來新增更多內容。

AGENTS.md 的用途

專案根目錄放有 AGENTS.md，記錄目標、設計風格、檔案結構、內容格式、安全規則與驗收方式。之後交給 AI 新增一篇筆記時，只需要先讀規則，就能延續相同的版面與品質。

使用技術

原生 HTML、CSS、JavaScript；不需要付費 API 或後端伺服器，可直接部署到 GitHub Pages。
